# Security Policy

## Authorized use

Web404 is intended for defensive security work on systems, domains, accounts, and data that you own or are explicitly authorized to assess.

Do not use the toolkit to access private systems, bypass authentication, collect exposed personal information, or obtain credentials or secrets without authorization.

## Reporting a vulnerability

If you find a security issue in Web404, please report it privately to the repository owner before public disclosure. Include the affected component, reproduction steps, impact, and a suggested mitigation when possible.

Never include passwords, API keys, access tokens, or other real secrets in a report.
